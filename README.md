# SAMWISE ADCS Flight Software - IMU only

Flight Software for the SAMWISE ADCS board


## Install Instructions
Install RPi Extension in VS Code.  
(Windows?  Then install cmake and ninja.  Mac and Ubuntu seems to be pre-installed).  
Click Debug to compile, flash and start the debugger.
Use Serial monitor to see the output.
In the lower right, select whether the board is pico or pico2.

Have fun!
